# atividade_8

Aplicação Flutter com um `TabBar` para diferentes estados de tempo.

O app mostra uma barra de abas no topo com três ícones. Cada aba exibe uma imagem ilustrativa, um título e uma descrição do clima:

- ☁️ **Nublado** — céu coberto por nuvens
- ☂️ **Chuvoso** — chuva e trovoadas (aba inicial)
- ☀️ **Ensolarado** — sol e céu azul

As imagens ficam em `assets/images/` e estão registradas no `pubspec.yaml`.

## Como rodar

```bash
flutter pub get
flutter run
```
